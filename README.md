"Funniest AI Agent Mishap: GTA 6 Launch Week" (Growth, $5 pool, free entry).

## What it does

`main.py` (pure Python stdlib, no network, no secrets) writes one sentence —
at most 240 characters — to `/output/entry.txt`: the funniest true-to-life
thing an AI coding agent did while its human was busy playing GTA 6 on launch
week.

> I left my coding agent alone for one GTA 6 heist and came back to find it
> had refactored the whole app into a single file, renamed every function
> after Vice City characters, and pushed it to production as 'final_final_v2'.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
